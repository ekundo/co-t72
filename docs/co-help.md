# Справка CO

<!-- co-help:skip -->

Текст встроенной справки CO. Отсюда собирается `CO.HLP`, который CO показывает
по клавише «1»:

```sh
python3 tools/mkhlp.py docs/co-help.md -o out/CO.HLP
```

Правится этот файл, а не `CO.HLP`: `patch-co.sh` пересобирает справку при каждой
сборке. Как маркдаун раскладывается по колонкам, написано в начале
[`tools/mkhlp.py`](../tools/mkhlp.py).

Текст авторский, правлен только там, где T-72 ведёт себя не как T-34: описание
клавиши «F2» в просмотрщике и допустимые символы в `CO.EXT`. Орфография и
разнобой в кавычках оставлены как были.

<!-- /co-help:skip -->

```screen
   Клавиши управления помощью:

   "стрелка вверх-влево" - выводить
              помощь на  весь экран
   "стрелка вверх"-предыдущий экран
   "стрелка вниз" - следующий экран
   "стр"   - переход к любой строке
   "АР2"        - возврат к панелям
   "F1" - подъем  окна  на 1 строку
   "F4" - опускание  окна на строку
```

## Краткое описание назначения клавиш:

- "F2" - устанавливает кодировку просмотра текстовых файлов. "RUS" -- файл в
  КОИ-7, русские буквы стоят на местах латинских; "LAT" -- показать русский
  текст латиницей; "R/L" -- переключение кодами 0Eh и 0Fh внутри самого текста;
  "K-8" -- файл уже в КОИ-8, коды не трогаются. На панелях это пресет: с ним
  просмотрщик и откроется, а внутри кодировку меняет та же "F2". При запуске
  программ кодировка не меняется: других наборов знакогенератора в T-72 нет.
- "F3" - помещает в командную строку предыдущую команду. запоминаются 14
  последних команды переданных DOS.
- "F1" - помещает в командныю строку следующую команду ( обратна "F3" )
- "F4" - помещает или добавляет в командную строку имя выделенного файла.
- "АР2"- если в командной строке что-то есть - очищает ее, если она пуста то
  изменяется значение клавиш 0,1..9, что отображается в самой нижней строке
  экрана. Эта клавиша обычно используется для выхода из различных функций и
  прерывания их работы.
- "стрелки вверх, вниз, СС+вправо, СС+влево"-перемещают курсор по панели.
- "стрелки вправо, влево" перемещают курсор по командной строке или панели.
- "стрелка вверх-влево" и "TAБ" -переводит курсор на другую панель.
- "СТР" -при пустой командной строке отмечает файл, а если в командной строке
  что-то есть - добавляет в нее имя и расширение выделенного файла.
- "ЗБ" - удаляет из командной строки один символ перед курсором.
- "-" - при пустой командной строке позволяет отменить все метки на активной
  пенели.
- "=" -отмечает на активной панели файлы, которые есть на другой панели.
- "/" -отмечает все неотмеченные файлы и удаляет метки с отмеченных.
- "?" -выводит размер файла с точностью до 128 байт.
- "ПС" - дополняет команду передаваемую DOS строкой ">C:CO.PTK".
- ";" - устанавливает курсор на файл начинающийся с символа введенного вслед за
  точкой с запятой.
- "+" - Отметить файлы по маске.
- "Пробел" - Востоновить системный экран.
- "ВК" -выполняется командная строка, а если она пуста то действия зависят от
  расширения выделенного файла. Действие, выполняемое для файла, определяется
  расширением его имени и задается в файле CO.EXT ( См. описание файла ) . Если
  выделен коталог пользователя то вы перейдете в этот каталог.

При пустой командной строке клавиши 0..9 имеют следующие значения:

- "1"-Помощь. Позволяет просматривать файл CO.HLP.

- "2"-Меню. Выдает список пользовательского меню из файла CO.MNU ( См. описание
  файла. ).

- "3"-Просмотр файла. Управляется курсором. Выход по клавише "AP2". Имеется
  команда "СТР", позволяющая перейти к любой строке просматриваемого файла.
  Клавиши "F1" и "F4" двигают окно по тексту на одну строку вверх и вниз
  соответственно. Eсли нужно сменить кодировку нажмите "F2", появится меню
  знакогенераторов. Выбор стрелками, фиксация клавишей "ВК" или "стрелка вниз".
  Просматриваемый текст можно распечатать, для этого необходимо нажать "F3". В
  версиях с 1.8 имеется возможность просмотра содержания файлов типа ".PK2" и их
  распаковки клавишей "BK" при наличии архиватора. Группу файлов можно отметить
  клавишей "СТР". Архиватор ARC2.COM лежит на диске, рядом с ним DEMO.PK2 --
  архив на посмотреть.

- "4"-Редактирование выделенного файла с помощью MEDIT.COM. Последний может
  находиться на любом доступном диске.

- "5"-Копирование отмеченных или выделенного файла на другой диск. После нажатия
  клавиши появляется сообщение вида: "диск-источник" => "диск-приемник", где
  "диск-приемник" соответствует неактивной панели. Если нажать "ВК" или стрелку
  вниз, будет осуществляться копирование. Можно переназначить диск-приемник,
  нажав соответствующую имени этого диска клавишу, а также отменть копирование,
  нажав любую другую клавишу. Прервать копирование группы файлов можно клавишей
  "АР2". Аналогично осуществляется выбор номера пользователя для
  диска-приемника.

- "6"-Изменение имени файла(ов).(см АР2+5) Отмена команды Клавишей "AP2";

- "7"-Позволяет сменить диск на активной панели или обновить информацию о нем.
  Перемещаться по меню, как и по всем другим подобным меню, можно с помощью
  клавиш "влево","вправо", а осуществить выбор клавишей "ВК" или "стрелка вниз".
  Для выхода из меню без изменений нажмите "АР2".

- "8"-Удаляет отмеченные или выделенный файл(ы).

- "9"-Выводит меню со следующими пунктами:
  - "Диск "B" - позволяет или запрещает программе "CO" искать файлы на диске B:.
    ( при разрешении, но реальном отсутствии диска B:, программа будет постоянно
    зависать ).
  - "Режим DIR" - устанавливает, выводить или нет на активной панели системные
    файлы. Если системные файлы не выводятся, то в оглавлении панели количество
    файлов указывается в виде суммы.
  - "Экран" - позволяет установить цвета символов и фона, а также время
    отключения монитора, при помощи клавиш "стрелка вверх" и "стрелка вниз".
  - "Копиров." - позволяет установить или снять режим проверки при копировании.
  - "Сорт" - позволяет выбрать режим сортировки файлов на активной панели.

- "0" - выключение монитора. Устанавливается нулевая таблица цветов.
  Восстановление - любая клавиша.


```
    После нажатия "СС"клавиши  1..9 меняют свое значение:
Этот режим можно зафиксировать клавишей "АР2"
```

- "1"-Изменяет вид вывода на активной палели: 40 или 60 файлов.

- "2"-Устанавливает атрибуты файла(ов).

- "3"-Просмотр в режиме КОИ-7. Удобно просматривать файлы редактора Word star

- "4"-Редактирование с помощью VDE.COM -- экранный редактор с клавишами
  WordStar, клавиши в нём по "^J".

- "5"-Копирование файла(ов) с заменой имени ( Для отмены команды достаточно
  нажать клавишу "AP2" ). Если не указывать расширение, то копия будет иметь то
  же расширение, что и оригинал. Если набрать ".TIP", то изменится только
  расширение. Можно использовать символы "*" и "?" эти места в имени останутся
  без изменения. Внимание! группу файлов можно копировать только при наличии
  маски.

- "6"-Записывает файл(ы) на магнитофон. Для записи файлов используются следующие
  программы:
```
DOS:-SAVEDOS.COM
BAS:-SAVEBAS.COM
COM:-SAVEROM.COM
MON:-SAVEMON.COM
ASM:-SAVEASM.COM
```
Если был выбран режим "По типу", файлы этих типов будут выгружены
соответствущими загрузчиками. Если "С указанием" - для каждого файла будет
выведено меню с возможными форматами. Оно будет выведено также и для файлов,
которые не могут быть выгружены по умолчанию.

- "7"-Если в Векторе есть винчестер, выбирает дискету НЖМД: спрашивает её номер
  (16-ричный, как в команде ОС "9"), назначает и перечитывает панель. Номер
  запоминается в файле CO.HDD и применяется при следующем запуске; если
  защитить CO.HDD от записи, выбор останется умолчанием. Без винчестера
  клавиша работает по-старому: выделенный файл выводится на принтер.
  Дополнительно запрашивается тип вывода. При выборе режимов "Набор 8" или
  "Альт код ГОСТа" происходит перевод с рабочего шрифта ( устанавливается по
  "F2" ) в соответствующий набор принтера. ( Наборы 8 и 4 принтера МС6313 )
  Последний позволяет выводить псевдографику. Прервать печать можно клавишей
  "АР2".

- "8"-Создание нового файла (см "5").

  Для редактирования нового файла удобней использовать комбинации клавиш
  "УС"-"4" либо "УС"-"СС"-"4"

- "9"-Отладка программ. Загрузка выделенного файла в SID.

  Комбинация клавиш "УС"-"СС"-"9" И "ВК" позволяет вызвать SID без файла


## Запуск программы "CO"

Для запуска программы с диска C:, на нем должны находится следующие файлы:
```
  1. CO.COM
  2. CO.PRM
```
Файл CO.PRM содержит информацию о параметрах программы: доступность диска "B",
делать ли проверку при копировании, вид вывода директория на каждой панели (
полный/краткий, системные файлы показаны или спрятаны ), директорий каких дисков
будет выведен на левой и правой панелях и т.д. Кроме этого файл CO.PRM содержит
14 последних команд, переданных программой "CO" операционной системе любым
способом. Их можно вызывать клавишами F1 и F3.

Кроме перечисленных имеются также следущие файлы:
```
3. CO.EXT
4. CO.MNU
5. CO.HLP
6. CO.ZGR
```
Файлы 3..6 могут располагатся на любом диске а "CO.ZGR" необходим только при
начальной загрузке (о чем далее) и при работе не нужен.

## CO.EXT

При нажатии пользователем клавиши "ВК" в момент, когда командная строка пуста,
программа "CO" может выполнить некоторую команду в зависимости от расширения
имени выделенного файла. какая именно команда быдет выполнена, указывается в
файле "CO.EXT", который может редактироваться любым текстовым редактором.

Каждая строка этого файла должна иметь вид: /расширение:команда/. в команде
можно использовать следующие символы для указания информации о выделенном файле:
```
  !    -диск и имя файла без расширения;
  !.!  -полное имя файла.
```
Например, если полное имя выделенного файла "C:PAPER.DOC" то значение этих
символов таковы: ! = C:PAPER , !.! = C:PAPER.DOC .

Расширение от команды отделяется двоеточием. Символы "L", "R", "К" и "/" на этом
месте тоже допустимы, но шрифт больше не переключают: других наборов
знакогенератора в T-72 нет.

Диск на котором находится программа, обслуживающая выделенный файл, указывать не
надо. "CO" сама определит, где она находится в момент обращения.

Список может содержать до 4-х строк с одинаковым типом файла. При этом исполнить
вторую строку можно нажав одновременно клавиши "CC" и "BK", третью "УС" и "ВК",
а четвертую "СС","УС" и "ВК".

## CO.MNU

Формируется пользователем и содержит набор командных последовательностей. Каждая
запись этого файла должна иметь вид:
```screen
N)  информация
A:команда 1
C:команда 2
.....
```
где N - цифра или буква, при нажатии которой будут выполнены команды,
расположенные ниже. Допустимы манипуляции с именами дисков и файлов.

В начале строки вместо диска можно поставить "X:" например:
```center
X:MARGO PROG.PAS
```
При этом будет произведен поиск файла MARGO.COM на всех доступных дисках и
символ "X" будет заменен на диск, на котором есть MARGO.COM. Поиск всех файлов
производится сначала на "C", потом на "A" и "B", если он доступен.

Вместо имени файла в последовательности команд можно поставить ! или !.!. При
выполнении команды будет подставлено имя выделенного на активной панели файла
без расширения или с расширением соответственно.

Файл CO.MNU должен заканчиваться строкой:
```
0) Возврат к панелям.
```
Если после строки с информацией есть только одна команда, то она выполняется и
управление возвращается программе CO. Иначе создается и выполняется командный
файл "CO.TOK". Для его удаления после выполнения список команд необходимо
дополнять строкой "E C:CO.TOK". Для возврата в CO необходимо также закончить
список команд командой "C:CO".

## CO.ZGR

Текстовый файл определяющий, при запуске оболочки с диска A:, какие файлы
необходимо загрузить на диск C:. Содержит по одному имени файла в каждой строке
и должен заканчиваться строкой содержащей одну точку. Файлы копируются начиная с
последнего в списке. Версия 1.10 может загружатса только с диска "A".

## CO.HDD

Заводит его сам CO, когда в Векторе есть винчестер и дискета НЖМД выбрана
клавишами "СС"-"7". Хранит номер этой дискеты: при следующем запуске CO
назначит её сам, ещё до панелей. Файл всегда лежит на диске C: и под нулевым
пользователем, где бы ни был запущен CO.

Чтобы закрепить номер насовсем, защитите CO.HDD от записи: выбранная дискета
будет назначаться при каждом запуске, а новый выбор в файл уже не попадёт.
Удалить файл тоже можно -- тогда CO просто ничего не назначает при старте.

Без винчестера файл не заводится вовсе, и пусковое назначение выключено: на
Векторе без НЖМД обращение к нему кончалось бы ошибкой диска ещё до панелей.
