# ПЗУ MDOS T-72

Сборка [ImproverX](https://github.com/ImproverX/MDOS_T-72) от 15.09.2026, GPLv3.

Лежат в репозитории, а не берутся из клона T-72: в самом репозитории ImproverX
последние правки исходников от 2022 года, а таблицу состава оборудования (`FFC9`)
он завёл позже и выложил только собранные ПЗУ. Собирать выпуск на ПЗУ из клона
нельзя -- CO тогда таблицы не находит и ведёт себя как на старой системе: не
показывает номер дискеты НЖМД и не знает, какие диски есть в машине.

| файл | оборудование |
|---|---|
| `os-t72f.rom`  | два НГМД и два квазидиска |
| `os-t72h.rom`  | НЖМД и два квазидиска, без НГМД |
| `os-t72hx.rom` | всё оборудование |
| `os-t72k.rom`  | только квазидиски |
