# MDOS T-72

Сборка [ImproverX](https://github.com/ImproverX/MDOS_T-72) от 16.09.2026, GPLv3.

`.rom` — формат, который понимает загрузчик Вектора: программа, стартующая сама,
без операционной системы. В нём поставляется и МикроДОС. Программы для самой
МикроДОС — это `.com`, в таком формате собран и CO.

Лежат в репозитории, а не берутся из клона T-72 на ходу: сборка там меняется, а
выпуск должен собираться воспроизводимо. Таблица состава оборудования (`FFC9`),
на которую опирается CO, появилась в сборке от 15.09.2026; в этой, от 16.09,
вдобавок работает автозапуск `INITIAL.SUB` с дискеты — на сборках, где есть
драйвер дисковода. Собирать выпуск на образе из
клона нельзя — CO тогда таблицы не находит и ведёт себя как на старой системе: не
показывает номер дискеты НЖМД и не знает, какие диски есть в Векторе.

| файл | оборудование |
|---|---|
| `os-t72f.rom`  | два НГМД и два квазидиска |
| `os-t72h.rom`  | НЖМД и два квазидиска, без НГМД |
| `os-t72hx.rom` | всё оборудование |
| `os-t72k.rom`  | только квазидиски |
